## ☁️ การเชื่อมต่อ Supabase Database & Storage (Cloud Setup)

1. สมัครใช้งานที่ [supabase.com](https://supabase.com) และสร้างโปรเจกต์ใหม่
2. ไปที่เมนู **SQL Editor** ใน Supabase
3. คัดลอกโค้ดทั้งหมดจากไฟล์ `supabase_schema.sql` ในโฟลเดอร์นี้ไปวาง แล้วกด **Run**
4. ไปที่ **Project Settings** -> **API** คัดลอก `Project URL` และ `anon public key`
5. กำหนดตัวแปรในไฟล์ `.env.local` หรือใน Vercel Environment Variables:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://xxxxxxxxxxxxxxxxxxxx.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
   ```

## 🌐 การนำขึ้น Vercel (1-Click Deployment)

1. ทำการ Push โค้ดทั้งหมดขึ้น GitHub:
   ```bash
   git add .
   git commit -m "feat: complete modern luxury electric portfolio for Aphinat.M"
   git push origin main
   ```
2. เข้าสู่ระบบ [vercel.com](https://vercel.com) แล้วกด **Add New Project**
3. เลือก Repository `portfolio` ของ `arm37240-dotcom`
4. ใส่ Environment Variables (`NEXT_PUBLIC_SUPABASE_URL` และ `NEXT_PUBLIC_SUPABASE_ANON_KEY`) หากมี
5. กดปุ่ม **Deploy** เว็บไซต์จะออนไลน์ทันทีทั่วโลก พร้อมโดเมน `.vercel.app` ฟรี
